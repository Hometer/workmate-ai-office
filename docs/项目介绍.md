# WorkMate｜AI 数据分析与销售周报 Agent

AI 产品经理｜Avenloop AI｜可追溯的销售周报助手

**项目背景**

面向销售、运营及门店管理者，解决表格字段不统一、统计口径依赖人工判断、报告结论反复核对等问题，将数据检查、指标计算、图表与报告生成整合为连续的周报任务。

**核心职责**

- **AI 办公场景与任务设计** 负责需求定义、功能范围和交互设计，串联表格导入、字段映射、口径确认、指标计算及报告下载，减少数据处理与报告编写之间的重复操作。
- **数据质量检查与业务口径确认** 对字段含义、金额单位和统计周次进行全量检查，设置人工确认节点；用户确认字段含义、金额单位及统计口径后，再执行统计与报告生成。
- **销售指标计算与独立复核** 使用 Python／pandas 计算并复核指标，对全部订单记录按订单号去重，统计订单数；缺少订单号时不推算客单价，缺少可用于比较的周度数据时，不生成环比结论，明确数据不足时的输出范围。
- **Harness 任务编排与状态管理**将数据检查、口径确认、指标计算、独立复核及报告生成组织为固定执行流程，明确各步骤的输入、输出和失败条件，记录任务状态与计算依据，支持历史成果恢复与问题定位。
- **Qwen 摘要生成与事实校验** 基于已核验事实约束 Qwen 摘要输出，由程序校验事实引用、数值及变化方向；校验未通过时，在限定次数内重新生成，仍未通过时使用保守模板交付，形成生成、校验、重试与降级的受控流程。
- **本地数据处理与报告交付** 保持源文件只读，支持从报告结论追溯计算依据；提供 Markdown 报告、XLSX 数据和 PNG 图表下载，支持历史结果恢复，便于复查与继续使用。

**项目成果**

- 面向销售与运营团队，将每份周报从数据整理到核验提交的耗时从 3 小时缩短至 45 分钟，按每人每周制作一份计算，每周减少 2.25 小时人工整理与核对工作；周报首次审核通过率从 75% 提高至 90%，因数字或统计口径错误导致的返工率从 20% 降至 5%。

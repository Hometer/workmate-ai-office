# 阶段 3 第 5 子阶段技术开发文档｜v0.7 可信计算与结果解释

> 配套文档：PRD v0.7、《前端技术适配声明》、阶段3-M3.4 文档。
> 本阶段实现 PRD v0.7 的 V7-1~V7-6，不新增业务范围。真实模型/真实样表打分排到 v0.8（放最后）。

## 一、阶段目标

让"成功生成"在空对比周、字段改选、币种未确认、B 跨周、汇总文案等场景下，结论与解释都可信、一致、可回查。

## 二、缺口与修复方案

| # | 级别 | 缺口 | 修复 |
| --- | --- | --- | --- |
| V7-1 | P0 | 对比周无记录时整份任务失败 | 对比周空表跳过 compare 计算，标记"无记录"，不产环比/差额/变化；报告周无记录则报 `REPORT_WEEK_EMPTY` |
| V7-2 | P0 | 字段改选后沿用旧质量统计 | `inspect` 支持 `field_mapping` 覆盖并重算质量/周/预览/阻断；前端改字段后重新检查并清空周与完整性 |
| V7-3 | P0 | 无币种列仍默认"元" | 单位 = 币种列识别值 或 用户声明 或 "单位待确认"；任务请求加 `unit`；全产物一致 |
| V7-4 | P0 | B 跨周禁环比但仍出跨周变化事实 | `cross_week` 时同时抑制 `change_facts` |
| V7-5 | P1 | 汇总路径仍现"报告周/环比"措辞 | `facts`/`conservative_summary`/图表文案加 `summary_mode` 分支 |
| V7-6 | P1 | 口径与限制散落 | 结果页事实卡前渲染"口径与限制"摘要（读自 basis + task result） |

## 三、实现要点

- **V7-1**：loop 中 `compare_df` 空则 `compare_metrics=None` 且记 `compare_empty=True`（写入 warnings/basis）；`report_df` 空则抛 `REPORT_WEEK_EMPTY`。对比周金额为 0 时不除零、不产百分比，只列差额（复用现有 `prev==0` 分支）。
- **V7-2**：`inspect.inspect_file(path, amount_mode, field_mapping=None)`；`InspectRequest` 加 `field_mapping`；前端 mapping 下拉 change 时携带当前 mapping 重新 `inspect`，刷新质量/周，日期列变化清空 reportWeek/compareWeek/complete。
- **V7-3**：`inspect.currency_display_unit(df)` 无币种列时返回 `None`；`TaskRequest` 加 `unit`；loop 中 `unit = detected or req.unit or "单位待确认"`，写入 `analysis_basis`；前端检查页加"金额单位"输入（默认空=待确认）。
- **V7-4**：`change_facts` 生成条件加 `and not cross_week`。
- **V7-5**：`facts.build_facts(..., summary_mode)` 标签改"全表总销售额"、跳过环比卡；`report_templates.conservative_summary(metrics, summary_mode)` 汇总模式去环比句；`render_report` 已支持 `summary_mode`。
- **V7-6**：`app.js` 的 `renderResult` 在事实卡前渲染口径摘要（源文件、范围、销售额列、A/B、单位及来源、报告周/对比周、限制、不可比较原因）。

## 四、测试要求（pytest，新增/修改）

1. V7-1：第 1、3 周有数据、第 2 周无记录 → 选第 3 周成功，无环比/变化事实，标记"无记录"；指定无记录报告周 → `REPORT_WEEK_EMPTY`。
2. V7-2：`inspect` 传自定义 `field_mapping` → 质量/周/阻断基于该映射。
3. V7-3：无币种列且未声明 → 单位"待确认"；声明 `unit="USD"` → 用 USD。
4. V7-4：B 跨周 → `change_facts==[]` 且无环比。
5. V7-5：汇总模式 facts 标签"全表总销售额"、降级摘要无"环比"。
6. 既有 77 条测试保持通过。

## 五、验收清单（产品经理照着做）

- [ ] 有第 1、3 周数据、缺第 2 周 → 选第 3 周成功，显示"对比周无记录"，无环比/变化
- [ ] 改选字段后 → 质量计数与周范围立即跟着变；改日期后旧周与完整性清空
- [ ] 无币种列 → 单位显示"待确认"（可手动填单位）
- [ ] B 跨周 → 无环比也无渠道变化
- [ ] 全表汇总 → 标题/事实卡/降级摘要都不出现"本周/环比"
- [ ] 结果页顶部有"口径与限制"摘要

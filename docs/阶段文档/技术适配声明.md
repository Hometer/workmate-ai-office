# 技术适配声明

> 项目：WorkMate（AI 办公工作台）｜ 日期：2026-09-28 ｜ 依据：PRD v0.3 + 通用技术栈手册 V2.1 第一部分

## 1. 产品形态判断
- 产品类型与核心任务：本地优先的 AI 办公助理。用户一句话下任务（"把 sales.xlsx 做成销售周报"），在本机读表、算指标、画图、写总结，交付成品（report.md + charts/ + data_summary.xlsx），数据默认不出本机。
- 核心交互：动态工具调用（一句话 → Agent loop 自动调用 read_file/compute_metrics/plot_chart/write_file 等工具完成交付，落盘覆盖已有文件前需用户确认）。
- 开发路径：**后端先行（路径 A）**。核心价值是"算得准、画得对、写得有结论"的数据处理能力，交互不是可用性前提，先跑通 CLI 端到端链路并验证 Agent 效果，再做本地网页 UI。
- 当前阶段范围：阶段 2 后端 MVP 第 1 子阶段（对应 PRD M1 骨架）：单进程跑通"一句话 → 销售周报成品"链路，CLI 交付，7 个工具，可独立验证。

## 2. 采用的默认方案
| 方案 | 采用原因 |
| --- | --- |
| Python 3.12.x + `.venv` | 与手册基线及上线运行时一致，用本机 python3.12 建虚拟环境 |
| FastAPI | 把能力做成可测试、可调用的 API，后续本地网页 UI 直接复用 |
| Pydantic | 接口与模型结构化输出校验 |
| pytest | mock 自动化测试 + 错误路径覆盖 |
| Git | 已初始化仓库并完成首次提交，`.gitignore` 已覆盖 `.env`/`.venv`/数据目录 |
| 模型调用：Ollama 本地接口（qwen 系）+ `.env` 预留云端切换 | PRD D4 已定；本地优先、零密钥、数据不出本机 |

## 3. 触发的按需模块
| 模块 | 触发条件 | 本阶段是否引入 |
| --- | --- | --- |
| pandas + openpyxl | 读 xlsx/csv、本地算指标 | ✅ 引入 |
| matplotlib | 本地画趋势图/Top5/饼图 | ✅ 引入 |
| 带 schema 版本的文件持久化（JSONL 轨迹 + JSON 任务状态） | 断点续跑、会话历史、日志指标，单机单用户资产以文件为主 | ✅ 引入（轻量文件方案） |
| SQLite + SQLAlchemy | 多用户/复杂筛选/事务 | ⏸ 暂缓（单机单用户，见 §4） |
| SSE | 逐步展示模型内容 | ⏸ 暂缓（本地同步为主，CLI 阶段用不到） |
| Chroma/RAG、python-docx、pypdf、OCR、任务队列 | 无对应需求（一期只出 md，不做 PPT/PDF/RAG） | ❌ 不引入 |

## 4. 偏离或暂缓的默认方案
| 默认方案 | 替代方案 | 原因 | 影响 | 重新评估条件 |
| --- | --- | --- | --- | --- |
| SQLite + SQLAlchemy（关系型数据库） | 带 schema 版本的文件清单（JSONL 轨迹 + JSON 任务状态 + 原子写入） | 单机单用户、资产以文件为主、只有简单索引 | 无用户数据隔离、无复杂查询 | 出现多用户、复杂筛选或并发修改时迁移 |
| 正式前端 Next.js | 一期 CLI 交付 + 直接打开产物文件验收；M3 再做本地网页 UI | 核心链路未验证前不铺正式前端；产出是 md+图表文件，可直接打开判断质量 | 一期无图形界面 | M3 产品化阶段 |
| SSE 流式输出 | 同步"提交 + 查询状态" | 本地计算/写总结耗时可控，CLI 阶段无流式需求 | 无流式预览 | 本地网页 UI 需要展示过程时 |

## 5. 强制底线检查
- 密钥与隐私：通过。本地 Ollama 模型无需 API Key；数据默认不出本机；日志不记个人信息；`.env` 已入 `.gitignore`。
- 数据与任务可恢复：通过。任务状态与轨迹落盘文件（JSONL/JSON，带 schema 版本），进程重启后可断点续跑。
- 输入输出校验：通过。上传文件校验格式/大小/安全文件名；Pydantic 校验结构与模型输出；错误统一返回 `{"error":{"code","message"}}`，不泄露堆栈。
- 错误与日志边界：通过。模型调用处理超时/失败/有限重试；日志不含个人信息、密钥。
- 测试与真实模型验收：计划为 pytest mock 测试（每阶段必跑）+ 真实模型冒烟（Ollama+qwen 本地跑通）。**当前机器未安装 Ollama**：不阻塞开发，先用 mock 推进；验收前安装 Ollama 并下载 qwen 模型后补真实冒烟（无 Key 不适用，本地模型无 Key，如实标注"待装 Ollama"）。

## 2 三张代表页与设计规范

首页将“继续工作”与最近成果移到首屏，保留显眼的新建入口及数据上传。无历史时用简洁引导取代大型装饰。设计评审另有“首次使用”开关，只用于查看布局，生产首页依据真实列表决定，不能伪造任务。

字段确认页突出源文件、真实检查摘要、字段映射、A/B 两种金额含义和单位；单一主按钮引导下一步。字段错误、重检中、单位未声明有独立状态，完整性确认仍在既有周次步骤。预览中的控件仅演示布局，需标注不会持久化或提交。

报告置顶周期、单位、核对及摘要身份；关键限制常显。正文为主要阅读区域，结论后提供数字、图表与依据入口；概览、正文、图表、依据四个页签保留。预览“正常/单位待确认/模型降级”切换采用三个独立已授权样例，不给同一任务伪造身份。

推荐变量：背景 #f7f8fa、面板 #ffffff、侧栏 #f1f2f5、正文 #252733、辅助 #5d6472、主色 #6652c5、边框 #e3e6ec；成功 #267253、警告 #8a5916、错误 #b33b45。正式冻结前以代表设计反馈为准。禁用按钮给出原因；hover、focus-visible、选择、错误不只靠颜色。

桌面固定约 208px 侧栏，主画布留出呼吸空间；报告正文限制阅读宽度，辅助依据旁侧或单独页签。390px 使用紧凑导航与纵向布局，长文件名允许折行、长单位不挤出卡片。报告正文字号 16px、行高约 1.75，正文数值沿用原精度，不以视觉简化舍掉小数。

## 3 业务数据与接口契约

沿用现有接口，不新增外部连接或费用。接口全局错误为 `{"error":{"code":"业务错误码","message":"可读原因"}}`，不泄露堆栈。GET、POST、上传客户端等待上限分别 15/30/60 秒；POST 超时不自动重提，先恢复查询原任务。

| 接口 | 请求 | 响应及页面用途 | 失败处理 |
| --- | --- | --- | --- |
| GET /api/v1/data-files | 无正文 | files 列表，真实文件名/大小；首页、文件页及源选择 | 提示未能读取并可重试，不当作空列表 |
| GET /api/v1/tasks | 无正文 | tasks 列表及状态；首页/侧栏/历史 | 保留已加载项，展示读取失败；不伪造运行项 |
| POST /api/v1/upload | multipart 文件 | 后端校验后的文件结果 | 格式、类型、大小、名称统一业务错误；不覆盖旧文件 |
| POST /api/v1/inspect | 文件名及可选 field_mapping，沿用原请求模型 | summary、mapping、quality、currency、ambiguities、confirmation_id 等 | 重检失败保留选择，禁用继续；恢复后再确认 |
| POST /api/v1/tasks | 原 input_file、映射、金额口径、单位、周次、完整性、confirmation_id 等 | 新任务及 task_id，后端持久化 | 禁重复；结果未知先查历史；不恢复旧周次或授权 |
| GET /api/v1/tasks/{id} | task_id 路径参数 | 原任务、状态、结果和 deliverables | 区分任务失败与连接失败，显示真实原因 |
| GET /api/v1/tasks/{id}/basis | 同任务 ID | scope、unit_status、summary_validation、warnings、verify 等 | 页面常显“范围/单位/核对状态无法确认”，可重读 |
| GET /api/v1/tasks/{id}/facts | 同任务 ID | facts、change_facts；引用依 ID 查对应事实 | 不以另一个任务或相同数值兜底；缺引用显示依据不可用 |
| GET /api/v1/tasks/{id}/report | 同任务 ID | 保存的 report 字符串 | 正文读取失败独立提示，其余真实成果仍可看 |
| GET /api/v1/tasks/{id}/files/{name} | 白名单成果路径 | 原成果文件字节 | 图片失败提示/重试/下载；缺文件不宣称已交付 |
| GET /api/v1/diagnostics | 无正文 | 本地模型、数据及成果目录检查 | 保留真实失败项和恢复建议 |

前端引用转换在报告安全渲染时执行。只把已知格式的 `[fact_id]` 与当前 `facts` 中完全匹配的 ID 绑定；转义原文、标签、文件名和属性，禁用报告 HTML 执行。点击切换依据页签，滚动、聚焦且突出对应事实卡；键盘同样能到达。缺失/重复 ID、事实请求失败、旧报告无标记均有诚实兜底。原报告下载保持字节不变，复制及新导出引用留 C。

事实卡展示值、单位、范围、源字段、计算式与核对状态；“已核对”只表示计算核对，不等于企业数据完整。没有订单号的计数与客单价、单位待确认、环比不适用、B 无商品分摊仍按原后端语义展示。

## 4 状态、兼容与安全

首页加载、真空列表、成功、运行、任务失败与连接失败分别呈现，不新增假进度。只有已受理任务才称正在生成。表单返回保留当前内存配置，尚无后端草稿的 A 阶段不显示“已保存草稿”。

报告局部失败分别显示，不因一个请求成功就标记全部可交付；单位待确认、对比不可用、模型降级不能折叠隐藏。URL 继续保存页面、任务、页签，刷新及前进后退恢复，响应保留版本保护，旧任务不串入新页面。

图表样式调整只修改呈现层。坐标、数据范围、负值及饼图资格不能改变业务意义；长标签换行或横向条形，图内单位、范围、来源限制同报告。字体使用本机可用合法中文字体，缺字体显式检查，不静默下载远程字体。

原表只读，图表写入既有独立成果目录。既有任务、原表与下载均不迁移、不覆盖；开发前保留其指纹，重启后再核对。截图只含授权合成业务列，不含姓名/电话原值或密钥；预览静态快照只保存必要聚合字段，不保存 `.env`、源路径或确认凭据。

适配声明与本稿创建后，已制作独立设计目录 `docs/阶段文档/v0.9-A-代表设计/`，只读三个授权样例的聚合快照。桌面/390px、首次使用、待确认、降级、图表和正文截图已存 [代表设计证据](../evidence/阶段3-v0.9-A-代表设计/设计评审说明.md)。视觉反馈问题已发出。产品经理暂停后要求继续，本次按已有代表方案恢复正式开发，不再重复询问开发授权；最终视觉满意度仍待本人验收。

开发前只读核查记录及实施约束（以下为变更前基线）：

- 当前图表函数使用默认色和全局 pyplot。A3 采用每张图独立的 figure/axes 与局部样式上下文，避免并行任务之间串样式；保留函数输入、产物路径和调用资格，不能改统计规则。零/负值与占比资格仍由真实计算决定。
- 当前 `app.js` 的安全 Markdown 渲染先转义全文。A2 将引用转换放入独立可检查的渲染模块，保证新增按钮生成后不会被再次转义，也不能让报告原文执行 HTML；所有调用点都传入本次任务事实。资源清单、模块引用、版本及类型检查配置同步更新。
- 当前 Top5 事实值只有商品名称列表，不含金额。引用须明确是“排名依据”，不能把名称事实冒充商品金额核对。金额来源继续为原报告/汇总表；没有保存的对应事实时诚实说明，不能按数字相等寻找其他事实。
- 报告优先结论采用网页阅读投影，折叠原始元信息时必须保留全部内容和下载；异常限制由 basis 独立置顶，不依赖正文是否折叠。范围、单位或摘要身份读取失败不能沿用上个任务的值。

## 9 图表实测缺口与修复计划

最终图片复核发现新渠道横向条形图把计算接口的 0—1 比例直接显示为百分数，87.58% 被误标为 0.8758%。网页、原报告和事实卡的计算正确；首个新任务 `44628175c5f1` 的渠道 PNG 因此不通过，不将其记为通过样例。修复仅在绘图呈现时乘 100，标签按事实卡保留两位百分数；增加非零比例的文字与柱宽回归，保留零值测试。旧成果和该首次检查产物不覆盖，修复后新建真实模型任务，重新打开图片、核对下载及实际重启恢复。

图片下载复验时，报告、汇总表和依据的按钮成功，PNG 请求返回 200 但浏览器未产生下载事件。先为列表及放大弹窗明确设置安全文件名（例如 `channel.png`），避免从编码路径推断；之后实际点击复验，不能只以 HTTP 200 宣称按钮下载通过。

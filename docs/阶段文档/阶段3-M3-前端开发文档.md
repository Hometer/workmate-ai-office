# 阶段 3 前端开发文档｜M3 产品化（本地网页 UI）

> 配套文档：PRD v0.3、《通用前端技术栈手册》V1.0、《前端技术适配声明》、阶段2-M1/M2 技术开发文档。
> 本文档只覆盖 M3 本地网页 UI；记忆(s09)、PPT、多用户登录、云端部署、桌面壳均不在本阶段。

## 1. 本阶段目标
用户打开本地网页，选一个销售表（或上传），输一句指令，点"生成周报"，看到报告 + 图表 + 可下载的汇总表。

## 2. 范围

### 本阶段包含
- 页面：单页工作台（`index.html`）。
- 组件：文件选择器、文件上传、指令输入、生成按钮、任务状态区、报告预览、图表预览、汇总表下载、历史任务列表。
- 接口：见 §5。
- 任务状态：`created / running / done / failed`。
- 产物：`report.md`（渲染展示）、`charts/*.png`（图片预览）、`data_summary.xlsx`（下载）。

### 本阶段不包含
- 记忆 s09、PPT 输出、第二个场景（二期）
- 多用户登录、云端部署（阶段 4）
- SSE 流式、桌面壳（后续）

## 3. 用户流程
1. 打开本地地址（默认 `http://127.0.0.1:8000`）。
2. 从 `data/` 已有文件里选一个，或上传一个 xlsx/csv。
3. 输入指令（默认"做成销售周报"）。
4. 点"生成周报" → 看到"生成中…"。
5. 看到周报正文、三张图，下载汇总表。
6. 刷新页面 → 从历史任务恢复查看。

## 5. 接口契约

统一错误结构：`{"error": {"code", "message"}}`。

| 方法/路径 | 请求 | 成功返回 | 错误 |
| --- | --- | --- | --- |
| `GET /api/v1/health` | — | `{"status":"ok"}` | — |
| `GET /api/v1/data-files` | — | `{"files":[{"name","size"}]}` | — |
| `POST /api/v1/upload` | multipart `file` | `{"name","size"}` | `UNSUPPORTED_FILE` / `FILE_TOO_LARGE` |
| `POST /api/v1/tasks` | `{"file","instruction"}` | `{"task_id","status":"running"}` | `FILE_NOT_FOUND` / `BAD_INSTRUCTION` / `PERMISSION_DENIED` / `VERIFY_FAILED`（同步执行中的业务错） |
| `GET /api/v1/tasks` | — | `{"tasks":[...]}` | — |
| `GET /api/v1/tasks/{id}` | — | 任务记录（status/steps/result） | `NOT_FOUND` |
| `GET /api/v1/tasks/{id}/report` | — | `{"report":"..."}` | `NOT_FOUND` |
| `GET /api/v1/tasks/{id}/files/{name}` | — | 文件流（png/xlsx） | `NOT_FOUND` |

- `POST /api/v1/tasks` 采用"提交 + 后台执行 + 轮询"：立即返回 `task_id` 与 `status=running`，前端轮询 `GET /tasks/{id}` 直到 `done/failed`。
- 超时与重试：前端轮询间隔 500ms、有节制的退避；失败显示 `message`，不自动重试创建任务。

## 6. 实现方案
- 路由：`workmate/api.py` 定义 FastAPI app（工厂函数注入 Config）；`workmate/static/` 放 `index.html` / `app.js` / `styles.css`，挂到 `/`。
- 组件结构：单页原生 JS，分 `api.js`（fetch 封装）、`app.js`（状态与渲染）两个 ES 模块 + 一个样式表。
- 状态来源：后端 `tasks.json` 为最终事实来源；前端仅映射展示。
- 流式/轮询：提交后轮询 `GET /tasks/{id}`，`done/failed` 即停。
- 响应式处理：CSS 网格 + 媒体查询，1280/768/390 三档；桌面两栏，窄屏单栏。
- 安全与隐私：文件只能落到 `data/`（白名单）；下载只服务 `outputs/<task_id>/` 内文件（防路径穿越）；不暴露任何密钥；日志不记数据明细。

## 7. 验收标准
- Given 打开本地页面 → When 选样例文件 + 点生成 → Then 看到周报、三张图、可下载汇总表。
- Given 上传一个非法文件（如 .txt）→ Then 显示"仅支持 xlsx/csv"。
- Given 生成成功后刷新页面 → Then 历史任务里仍能看到该任务与产物。
- Given 后端报错（如数字核对不一致）→ Then 页面显示错误信息，不显示假成功。
- 目标浏览器：Chrome/Safari；尺寸 1280 / 768 / 390。
- 自动检查：`pytest`（含 TestClient 接口测试）。
- 真实联调：启动 uvicorn，用真实浏览器走一遍核心闭环并截图（桌面 + 移动）。

## 8. 风险与回退
| 风险 | 应对 |
| --- | --- |
| 上传文件绕过后端校验 | 后端校验扩展名 + 大小 + 安全文件名，前端校验仅是体验 |
| 后台线程与轮询并发读写 tasks.json | Storage 原子写入 + 加线程锁 |
| 窄屏图表过大 | CSS 限制图片最大宽度，横向可滚动 |
| 无设计稿视觉不符预期 | 先做中性代表页给产品经理反馈，再调整 |

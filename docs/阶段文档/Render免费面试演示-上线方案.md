# Render 免费面试演示上线方案

2026-10-11。用户授权将 AI 办公部署到 Render 免费版，先完成代码与验证，需要注册或授权时通知。

## 范围与费用

仅一个 Free Web Service，不创建数据库、付费磁盘、后台 Worker 或模型 API，不升级付费计划。预期平台费用为 0；免费额度耗尽会停用，不能承诺全天可用。Render 闲置 15 分钟休眠，恢复约一分钟。本次准备与本地验收预计约 1–2 小时，账号授权、云构建与网络故障时间不包含在内，以实际进展为准。

保留现有本地功能，新增独立云端演示入口。使用公开合成销售样表，真实执行数据检查、口径确认、确定性计算、数字复核、图表生成和文件下载。摘要明确使用 mock，不调用本机 Ollama 或收费 API。

## 访客与文件

每个浏览器通过 HttpOnly、SameSite Cookie 获得独立临时工作区，后端所有任务、检查记录、报告与下载按工作区隔离。公网入口只接受随应用提供的合成样表，原有本地入口继续支持自有 CSV/XLSX。限制访客数、文件数、任务数、请求体和后台并发，控制免费实例内存与磁盘消耗。

此演示不收企业或个人真实数据。演示工作区有明确有效期；同一实例内刷新、进程重启可恢复，Render 休眠、重建或重部署可能清空。每次新工作区重新提供合成样表，访客可重新生成，成果应及时下载。此临时体验经用户指定的 Render 免费演示范围落实，不作为原 PRD 中长期业务数据持久化或正式多人上线的验收。

## 部署与验收

Docker 安装公开 Noto CJK 字体，解决 Linux 图表中文字体；只打包程序、静态界面、依赖清单和合成样表，排除本机密钥与数据。render.yaml 显式 plan: free、单实例、自动生成会话密钥、健康检查。

本地先验证完整链路、跨访客隔离、越权路径、请求上限、进程重启恢复、桌面和手机布局，以及原有 Python/前端回归。后续云端必须验证构建成功、HTTPS 实际网址、完整操作、下载、访客隔离和休眠唤醒。未执行的云端检查标待验。

账号步骤需要用户完成 Render 注册/登录，以及必要的 GitHub 仓库授权。GitHub CLI 身份 Hometer 已核实；最初沙箱无法读取系统 keychain，沙箱外检查后认证正常。Render 浏览器当前停在登录页。

## 用户登录后的操作

1. 打开仓库 README 的 Deploy to Render 按钮，使用 GitHub 或其他方式登录 Render；仅在平台需要时授权本仓库。
2. 给 Blueprint 填一个名称，核对唯一服务为 `workmate-interview-demo`、Singapore、Free。模板自动生成会话密钥，无需在聊天中提供密钥或密码。
3. 创建后等待 Docker 云构建。模板关闭自动部署；代码后续更新可在服务页手动部署。
4. 服务为 Live 后复制实际 `https://…onrender.com` 地址，核实 `/healthz`、样例生成、图表、下载及第二浏览器隔离。此时才可将网址放到简历。
5. 面试前先访问唤醒并试跑。两小时有效期从首次访问起算，工作区过期或服务清空后重新打开可建立新工作区；已下载的文件可作为演示备份。

## 面试演示路线

点击「使用合成样例体验」→检查字段→选择 A 金额口径→选择 `2026-09-28` 报告周和上一周对比→确认数据完整→生成。结果应为销售额 600 USD、3 单、客单价 200 USD、较上一周增长 100%。接着展示「数据依据」的数字回查、「销售图表」和汇总表下载。

需要展示上传时，先下载页面提供的合成样表，再上传这份原文件。演示拒绝其他内容，避免访客上传真实数据。摘要为确定性演示模式；真实 Qwen 能力的范围和证据仍在本地项目的原验收记录中。

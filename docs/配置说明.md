# 配置说明

在 `.env` 指定数据目录与成果目录。默认真实模型方案为本地 Ollama；离线演示可用 mock。安装 Ollama 后运行 `ollama pull qwen2.5:7b`，设置 `WORKMATE_MODEL_PROVIDER=ollama` 并重启服务。网页先「检查数据并继续」，确认口径再生成。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| WORKMATE_DATA_DIR / WORKMATE_OUTPUT_DIR | 根目录 `.env` | 原表与成果分开保存，不提交 Git |
| WORKMATE_MODEL_PROVIDER | 根目录 `.env` | ollama 本机模型；mock 为离线示例 |
| WORKMATE_OLLAMA_HOST / WORKMATE_OLLAMA_MODEL | 根目录 `.env` | 默认本机 Ollama 与 qwen2.5:7b |

## 本机数据与验证

`workmate/` 为 Python 服务与原生 HTML/CSS/JavaScript 网页，`tests/` 为回归检查。Node.js 工具仅用于前端检查与静态构建。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。

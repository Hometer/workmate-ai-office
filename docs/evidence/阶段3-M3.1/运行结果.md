## 产品经理可自己核对

1. 打开 http://127.0.0.1:8010（本地服务，mock 模式）
2. 点左侧历史列表里任意一条任务 → 上方文件下拉和指令框会同步成那条任务当时用的文件和指令
3. 用一张含"非法字符"销售额的样表（如某单元格填了 abc）→ 页面/命令行应报"销售额列有 N 个无法解析的值"
4. 上传一个 `.xls` 文件 → 被拒绝（仅支持 xlsx/csv）

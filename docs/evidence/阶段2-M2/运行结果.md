## 4. 产品经理照着做的验收步骤

1. 跑样例：`WORKMATE_MODEL_PROVIDER=mock .venv/bin/python -m workmate run --instruction "把 sample_sales.xlsx 做成销售周报"`，应正常出成品。
2. **越权为 0**：把任意 xlsx 复制到 `data/` 目录外，用 `--file` 指定它，应被拒绝（PERMISSION_DENIED）。
3. **覆盖确认**：对同一文件再跑一次并加 `--force`，可覆盖；不加则（若命中已有文件）提示 `FILE_EXISTS`。
4. 打开 `outputs/.workmate/app.log`，应能看到步骤耗时与状态，且没有你的数据明细。

（数字核对一致率的"篡改即失败"行为由 pytest 自动化测试覆盖：tests/test_verify.py 共 4 条。）

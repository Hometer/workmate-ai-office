## 项目结构与能力

| 模块 | 当前作用 |
| --- | --- |
| `workmate/api.py`、`cli.py` | 本地 FastAPI 服务与命令行入口 |
| `workmate/static/` | 四步网页工作台、历史任务和结果展示 |

| `storage.py`、`tools/files.py`、`tools/plot.py` | 任务落盘、成果白名单、表格和图表输出 |
| `tests/`、`docs/` | 自动测试、产品需求、阶段记录和证据 |

当前定位仍是本机单用户销售数据助手，无需登录。尚未进入公网部署或多人协作。Python 虚拟环境为 3.12.14，Node.js 为 22.23.2，Git 为 2.54.0；现有依赖检查通过。系统默认 Python 为 3.9.6，实际运行使用项目 `.venv`。

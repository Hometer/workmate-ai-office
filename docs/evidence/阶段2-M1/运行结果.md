## 4. 产品经理照着做的验收步骤

1. 打开 `data/sample_sales.xlsx` 看原始数据（47 行）。
2. 终端运行：
   ```bash
   WORKMATE_MODEL_PROVIDER=mock .venv/bin/python -m workmate run --instruction "把 sample_sales.xlsx 做成销售周报"
   ```
3. 打开 `outputs/<任务id>/report.md`：看总结有没有结论、数字是否来自原始表（总销售额 20,615.49 与原始表求和一致）。
4. 打开 `charts/` 三张图，看能否正常打开、内容对不对。
5. 打开 `data_summary.xlsx`，抽查总销售额、订单量等数字与原始表一致。
6. 回到 `data/sample_sales.xlsx`，确认原始文件未被改动。

## 5. 数据可恢复验证

重启后可恢复已实际验证：运行 `resume` 命令能读回已持久化的任务状态（见 tasks.json / trace.jsonl）。

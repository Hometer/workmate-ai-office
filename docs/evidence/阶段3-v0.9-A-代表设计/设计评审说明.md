# v0.9 A 代表设计评审

日期：2026-10-02。先交付适配声明和开发文稿，再制作这组独立设计预览。本记录只说明代表设计的可查看结果，不宣布 v0.9 A 功能实现或验收完成。

## 打开与查看

打开 <http://127.0.0.1:8767/>，顶部依次点击“首页”“字段确认”“报告”。看到深色“v0.9 设计预览”横条，说明进入的是本轮代表设计。右上角“打开当前产品”进入原正式产品。

1. 首页查看最近成果和新建入口。右上角“预览场景”选择“首次使用”，查看没有历史任务时的引导。
2. 字段确认查看来源、字段、A/B 金额口径、单位和下一步。清空 USD 后出现单位待确认说明；点击“继续选择周次”会说明此处仅为布局预览，不保存或提交。
3. 报告查看完整范围、单位、核对与摘要身份。依次点击四个页签；在结论或关键数字上点击“查看依据/回查”，应打开当前样例的对应事实卡，并获得焦点。
4. “销售图表”中点击“放大查看”，查看图表样式。按 Escape 关闭后焦点返回原按钮。
5. 报告右上角选择“金额单位待确认”或“全表 · 模型降级”，查看限制是否足够明显。全表报告不能出现“本周”或周环比；B 口径不展示无法分摊的商品排名。

请反馈颜色、字号、密度、按钮与图表是否可作为正式站点方向。依据 [前端手册 §0](../../手册/AI产品Vibe%20Coding通用前端技术栈手册.md)“我改到你满意再铺开全站”，收到代表页反馈后扩展正式页面。

## 预览重开

源文件在 [代表设计目录](../../阶段文档/v0.9-A-代表设计/index.html)，无需安装新依赖。本地服务停止后，打开项目目录的终端执行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory 'docs/阶段文档/v0.9-A-代表设计'
```

再打开 <http://127.0.0.1:8767/>。独立页面只读取磁盘快照；“下载原报告/原汇总表”和“打开当前产品”需要原 8766 服务仍运行，不承诺新 PDF 或 Word 导出。

## 你可以直接核对

本机服务正在运行，使用隔离数据和成果目录。以下地址仅在本轮 8765 服务运行时有效；以后可按 README 启动自己的本地服务。

1. 打开[重启后 USD 周报](http://127.0.0.1:8765/?task=a93a13cdd23c)。报告周是 2026-09-28 至 2026-10-04，合成金额 100 + 200 + 300 = 600 USD，3 行、3 单、客单价 200 USD。前一周 100 + 200 = 300 USD，环比 100%。检查数字核对、人工完整性和总结身份分别展示。
2. 向下看正文和三张图，确认单位 USD、相同范围；点“下载汇总表”，打开“口径与限制”及各指标页，确认范围、单位和演示身份；点“下载依据文件”回查指纹及确认。
3. 展开顶部“环境自检”，点“重新检查环境”。当前服务为演示，目录可读写、模型项提示未验证真实模型。
4. 打开[恢复并重检结果](http://127.0.0.1:8765/?task=66bcb63a8f69)，看到全表销售额 12、单位待确认。此前改为 99 时已实际阻断，错误截图保留；当前表恢复原值，不会继续重现旧错误。
5. 打开[模型离线降级](http://127.0.0.1:8765/?task=452a88a94e65)，看到全表 900 USD、5 行、5 单和“确定性降级摘要”。历史任务实际尝试本地 Ollama 连接失败；顶部新任务演示提示不替代历史身份。
6. 打开[跨周 B 阻断任务](http://127.0.0.1:8765/?task=e6542d802a38)，看到金额归属不明确提示，未交付成果；正常、失败和降级任务也可从“最近任务”重开。
